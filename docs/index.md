# Model123d

Welcome to the **Model123d** documentation! This is a comprehensive 3D modeling collection of parametric models built with [build123d](https://build123d.readthedocs.io/) (Python-based OCCT).

!!! info "Project Overview"
    **model123d** is a parametric 3D modeling collection that generates STL and 3MF files for 3D printing. All models are programmatically created using Python, making them easily customizable through parameter adjustments.

## ✨ Features

- **🎯 Parametric Design**: All models are fully parametric and customizable
- **🐍 Python-based**: Built with build123d, a powerful Python CAD library
- **📁 Organized Structure**: Models grouped by category and use case
- **🔧 Easy to Use**: Simple parameter adjustment for customization
- **📤 Multiple Formats**: Export to STL, 3MF, and STEP formats
- **🎨 VS Code Integration**: Built-in 3D visualization support

## 🎯 Featured Models

### 🎲 [Base Plates for Miniatures](models/base-plates.md)
Hexagonal and circular bases for tabletop gaming with integrated magnet holes.

## 🛠️ Technology Stack

- **[build123d](https://build123d.readthedocs.io/)** - Python-based OCCT modeling library
- **[ocp-vscode](https://github.com/bernhard-42/ocp-vscode)** - VS Code integration for 3D visualization
- **[Rich](https://rich.readthedocs.io/)** - Enhanced terminal output
- **[lib3mf](https://github.com/3MFConsortium/lib3mf)** - 3MF file format support
